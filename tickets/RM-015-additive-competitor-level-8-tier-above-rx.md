## Problem
Rx is a single open-ended bucket set at strong-amateur level; a recreational beast and a Semifinalist look identical, so the scale has zero resolution above the regional-amateur line.

## Proposal
Add an ADDITIVE Competitor tier anchored to public CrossFit Open / Quarterfinal / Semifinal percentile cut-lines, with graded sub-tiers replacing the open-ended 99 max-rep buckets — WITHOUT disturbing the existing general-population levels 1-7.

## Acceptance criteria
- [ ] New tier sourced to public competition cut-line data.
- [ ] Levels 1-7 percentile mapping unchanged.
- [ ] Max-rep buckets graded rather than open-ended at the top.
